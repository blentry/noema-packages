# Noema packages

Official sources for coherent theory units, explicit mappings and system compositions.

Install the CLI from the commit in `noema-tool.json`, run `noema tools prepare`,
then run `noema registry search examples/winding-loss` and follow an example README.
The motor/thermal/control set is a static integration fixture, not a validated motor theory.
Release metadata is maintained in https://github.com/blentry/noema-register.
